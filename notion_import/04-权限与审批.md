# 权限与审批

此页是待企业确认的配置建议，导入不会执行授权。

| 角色 | 建议范围 | 人工验收 |
|---|---|---|
| 企业管理员及备份管理员 | 管理结构、成员与交接 | 企业长期持有账号；离职回收可执行 |
| 部门主管/内容负责人 | 审阅本部门草稿、核准版本 | 有可追溯的审核记录 |
| 普通员工 | 查阅已发布SOP，按指定入口反馈问题 | 实测不能随意更改已发布内容 |
| 外部顾问 | 仅试点所需页面、限期访问 | 到期可撤销，不使用公开链接替代授权 |

需要限制已发布 SOP 编辑时，可将发布资料放入只读权限边界或适当的企业权限机制；不要把“锁定数据库”“隐藏属性”“已发布视图”当成安全隔离。实际功能取决于套餐和工作空间设置。

建议内容状态：草稿→待审核→已发布→待修订/归档。状态字段只是记录，不会自动实施审批或阻止越权更改。发布前由主管确认负责人、审核人、版本、生效/复审日期与正文。生成器对已发布记录检查必要字段，无法证明批准记录真实存在。

先由企业决定允许存入的客户/员工数据类型、保密等级和访问范围，再导入正式内容。用实际办公网络验证登录、编辑、上传及响应。付费套餐和跨境数据事项由企业另行确认。
