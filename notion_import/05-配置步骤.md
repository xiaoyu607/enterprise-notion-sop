# 手动配置步骤

企业：{{company_name}}；数据模式：{{mode_label}}。

1. 企业指定管理员和备份管理员，选择获授权的目标页面/团队空间。
2. 用实际员工网络验证 Notion 可访问，确认本次允许存储的数据范围。
3. 在 Notion 桌面/网页的 Settings → Import 选择 ZIP（Convert Zip to pages），也可在页面输入 /zip。只选择本包一个模式的 ZIP。
4. 核对10份说明页、8个CSV对应的数据库及SOP正文。ZIP可能部分成功；失败重试前先检查已导入的记录，不要直接重复导入。
5. 若ZIP里的CSV未成为数据库，解压后通过 Settings → Import → CSV 逐个导入，核对标题与属性映射。正式包若只有表头、Notion不接受空CSV，请按字段字典手动创建8个空数据库，不能加入演示行充数。
6. 设置字段类型：日期、人员、选项与多选。编号先保留文本。关系目标库全部建立后，再按编码创建和逐条验证 Relation，必要时增加 Rollup/Formula。
7. 配置8库视图，更新首页中的真实页面链接；包内相对链接是否能转换需实测。
8. 在隔离测试页演练样例。正式部署仅用正式包；正式包默认空数据，须由企业提供真实岗位和记录。
9. 将正式SOP正文放入相应数据库条目，核对负责人、审核人、版本与生效/复审日期，并由主管审阅。正文路径不会自动绑定页面。
10. 配置访问权限和成员，测试普通员工不可改已发布制度、未授权人员看不到敏感内容。
11. 按套餐配置提醒/复审；无法自动化时指定人工巡检人和周期（建议 {{review_cycle_days}} 天，以企业约定为准）。演练新人培训与问题关闭。
12. 完成岗位实操、管理员培训、备份与权限交接，再逐项签署验收。

CSV/ZIP导入不会自动建立所有关系、权限、审批、视图或提醒。导入会新增内容，不能当作幂等更新工具。

官方依据（2026-10-27核验）：[Notion 导入说明](https://www.notion.com/help/import-data-into-notion)、[关系与汇总](https://www.notion.com/help/relations-and-rollups)。实际入口随产品更新时以官方说明为准。
