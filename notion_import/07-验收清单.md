# 业务验收清单

本包生成成功不代表业务已验收。下列项目由企业现场验证并记录结果和证据。

- [ ] 首页能访问8个主要数据库。
- [ ] 8库字段、标题、中文和记录数正确，日期日月无颠倒。
- [ ] 3–5份实际试点SOP经主管批准。
- [ ] 每份正式SOP有正文、负责人、审核人、版本和日期。
- [ ] 普通员工能在3分钟内找到指定岗位SOP。
- [ ] 普通员工不能随意修改已发布SOP。
- [ ] 未授权人员无法访问敏感记录。
- [ ] 员工可报告问题，主管可审阅并关闭。
- [ ] 到期提醒或人工复审实际可执行。
- [ ] 至少3类岗位完成模拟任务并留下记录。
- [ ] 企业拥有管理员权限、备份和权限回收说明。
- [ ] 双方书面确认交付范围与后续维护边界。

记录格式：验收项、执行账号/角色、日期、预期、实际、证据、结果、遗留事项与负责人。尚未执行的项目标“待验收”，不可改为“通过”。
